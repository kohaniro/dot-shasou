# サブエージェントの時間の内訳

Agent ツールで起動したときに返る `output_file`（`…/tasks/<id>.output`、JSONL）を渡す。中身は読まずに合計だけ出すので、枠を使わない。**記録を Read で直接開かないこと**（大きすぎる）。

```bash
node .claude/skills/agent-time/agent-time.mjs "<output_file のパス>"
```

- 「実働」は、5分を超える空白（利用枠の上限や認証エラーでの中断）を除いた時間。
- 「モデル: 思考」が大きければ effort を下げる余地がある。「ツール実行: Bash(shots 撮影)」が大きければ、撮る絵柄・シードを絞る。
- 出力トークン ÷ モデルの生成時間 で、出力の速さの目安が出る。
