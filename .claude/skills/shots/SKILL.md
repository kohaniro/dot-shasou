# 景色のスクリーンショット

描画を変えたら、このスクリプトで画像を出し、Read で開いて目で確かめる。依存なし（インストール済みの Chrome か Edge を使う。見つからなければ環境変数 `CHROME_PATH`）。確認用サーバーが止まっていれば自動で起動する。

```bash
node .claude/skills/shots/shots.mjs <出力フォルダ> <シード,シード> <絵柄,絵柄> [mode]
# 例: 2つのシード × 4つの絵柄で、景色だけの絵と車内込みの画面を保存
node .claude/skills/shots/shots.mjs "<scratchpad>/shots" 1234,7 real,soft,game,mono both
```

- **出力フォルダ**はプロジェクトの外（セッションの scratchpad）にする。省略すると OS の一時フォルダの `dot-shasou-shots`。
- **絵柄**: `real` / `soft` / `game` / `mono`
- **mode**（省略時 `both`）

| mode | 出すもの | ファイル名 |

| `raw` | 車内を重ねない景色だけの絵（幅480ドット、2倍） | `raw-<シード>-<絵柄>-a.png` / `-b.png` |
| `view` | 車内・乗客込みの実際の画面 | `view-<シード>-<絵柄>-a.png` / `-b.png` |
| `both` | 上の両方 | |

| `pano:<距離,距離>` | 指定した走行距離の、横1280ドットの絵（チャンクの継ぎ目の確認） | `pano-<シード>-<絵柄>.png` |
| `at:<距離,距離>` | 指定した走行距離（`state.dist`。窓の中央の地点は +160）の、車内・乗客込みの実際の画面を縦に並べる（坑口の手前・直後など、任意の地点の確認） | `at-<シード>-<絵柄>.png` |
| `zoom:<距離,距離>` | 指定した走行距離の4倍拡大 | `zoom-<シード>-<絵柄>.png` |
| `perf` | レイヤーごとのチャンク生成時間を表示（画像なし） | |

| `swap` / `swap:<k,k>` | 駅での乗客の入れ替え。駅 k（省略時 1,2）に停車し、車内込みの画面を「降りる人が立った直後」「降りる人が歩いている途中」「乗る人が入ってきたところ」「乗る人が歩いている途中」「全員が座ったあと（ドアが閉まる前）」「発車後」の6コマ縦に並べる。各コマの `stopT`、降りる人・乗る人の席番号、`dwell`、ずらす間隔と速さの倍率を表示。あわせて、区間3の顔ぶれが直接求めても順に求めても同じか、駅 1〜12 で全員が `tl.close` より前に座り終えるか（`margin`）も表示する | `swap-<シード>-<絵柄>-k<k>.png` |

## 時間帯と天気

既定では**昼・晴に固定**して撮る（時間帯・天気を入れる前の画像と同じ絵になる）。環境変数で変える:

```bash
SHOTS_TOD=night node .claude/skills/shots/shots.mjs "<scratchpad>/night" 1234 real tunnel:1   # 夜のトンネル
SHOTS_TOD=auto SHOTS_WX=auto node .claude/skills/shots/shots.mjs "<scratchpad>/auto" 1234 real run   # 走行距離から決まる時刻・天気のまま
```

- `SHOTS_TOD`: `auto`（走行距離から決まる）/ `dawn`（5:30）/ `noon`（既定）/ `dusk`（18:00）/ `night`（0:00）/ 時刻の数値（例 `17.25`）
- `SHOTS_WX`: `auto` / `clear`（既定）/ `cloud` / `rain` / `snow`。`cloud:0.5` / `rain:0.5` / `snow:0.5` のように強さ（0〜1）を付けられる（`cloud:` は曇り具合、`rain:` / `snow:` は降りの強さで、雲は一面）
- 景色だけの絵（`raw` / `pano:` など）は、絵の中央の地点のトーン1つで全体を描く（`auto` で横に長い絵を撮っても、途中でトーンは変わらない）。
- `SHOTS_HOURS=17,17.5,18,18.5,19`: `tod` mode の4コマ（朝焼け / 昼 / 夕焼け / 夜）の代わりに、並べた時刻を順に撮る（夕方・朝の移り変わりの途中の段階を見比べる）。
- `SHOTS_WXS=clear,cloud:0.25,cloud:0.5,cloud:0.75,cloud,rain:0.5,rain`: `wx` mode の4コマ（晴 / 曇 / 雨 / 雪）の代わりに、並べた天気を順に撮る（天気の移り変わりの途中の段階を見比べる）。
- 雨脚・舞う雪・窓ガラスの水滴は毎フレーム描く層なので、車内込みの画面（`view` / `at:` / `station` など）にだけ出る。景色だけの絵（`raw` など）には、チャンクに焼き込む分（色調、雲、積雪、濡れた面のてり、灯りの映り込み）だけが出る。停車中と走行中の水滴の違いは `SHOTS_WX=rain` の `station` で見る。
- `clock` / `tonerun` は環境変数によらず固定を外す。`tod` は時間帯を、`wx` は天気を自分で固定する。

`run` は 30 秒ごとの進行の状態（`dist` / `speed` / `phase` / `door`）も表示する。

`raw` / `view` は、「各バイオームの中心6点（a。最初に現れた区間。山間と海沿いは別の周になる）」と「遷移の境目5点（b。隣り合う組ごとに最初の1回）」を縦に並べた1枚にする（区切りはマゼンタの帯）。撮る地点の走行距離は実行時に表示されるので、`pano:` / `zoom:` の距離指定に使える。

景色だけの絵（`raw` / `pano:` / `zoom:` と各 mode の `-raw-`）は、高架の下げ幅（`Layer` の `drop` × `elev`）は反映するが、カーブの上下のずらし（カント）と揺れは反映しない。

## 出力の読み方

- `deterministic: YES` — 同じ条件で2回描いて同じ画像だった。`NO` なら生成コードに `Math.random()` や時刻への依存が紛れている。
- `Math.random calls` — 景色の生成中に呼ばれた回数。0 であること。
- `CONSOLE ERRORS: none` であること。

## 注意

- 時間と `Math.random` を差し替えた固定ステップでの確認なので、実ブラウザでの滑らかさや音は確かめられない。
- 画像を開くと枠を多く使う。まず `raw` を1シード・`real` で見て、問題なければ残りの絵柄を見る。全部を開く必要はない。
- バイオームを足したり `world.js` の公開名（`world` / `BIOME_KEYS`）や `state` の形を変えたりしたら、スクリプト内の `__plan` / `__goto` も合わせて直す。
- チャンクを `L.chunk(i)` で直接作る確認を足すときは、先に `tone.js` の `snapToneAt(dist)` を呼ぶ（呼ばないと、直前の描画のトーンで描かれる）。`__raw` と `__fix` は呼んでいる。
- `__goto(距離, stopT)` は `journey.js` の `seekJourney()` で進行の状態（`phase` / `station` / `door`）もその地点に合わせて置き直す。駅の `pos` ちょうどに飛ぶと停車中（`stopT` 秒後）になる。`view` の地点が駅の前後（減速・加速中）に当たると、2フレーム進む距離が巡航時と変わるので、駅を入れる前の画像とはハッシュが一致しない。
